Node.js ماشي language جديدة

عندك JavaScript و TypeScript. وعندك شوية Node. اليوم غير فكرة وحدة: نفس الـ language، بلاصى أخرى، بـ permissions مختلفة.

Browser Node.js نفس JS

1

🎯 شنو كنتعلمو؟

Node.js هو runtime: program كيجري JavaScript على الـ computer أو الـ server، ماشي داخل Chrome.

2

🤔 علاش فهاد الـ course؟

الـ eval harness، calls ديال الـ LLM، وغالباً الـ agent غادي يعيشو هنا: فـ Node. الـ UI تبقى React.

ما غاديش ندوزو لـ Python. نفس الـ language اللي كتعرفيها، غير الـ environment تبدّلات.

3

🧠 شرح دارجة

فـ browser، JS كيشوف الـ page: document، window، الـ buttons. ما يقدرش يقرا file من الـ disk بسهولة، وما يقدرش يفتح port 3000.

فـ Node، ما كاينش page. كاين: files، network، environment variables، npm. ما كاينش document.getElementById.

المصدر الرسمي: Node كيجري محرّك V8 (نفس قلب Chrome) برا الـ browser. Introduction to Node.js

4

🌍 تشبيه

JS فـ browser

بحال طبّاخ فالقاعة: كيشوف الزبناء والطاولات. ما يدخلش للمخزن ديال العمارة.

JS فـ Node

بحال طبّاخ فالمطبخ: ما كيشوفش القاعة، ولكن كيوصل للفرن، الثلاجة، وباب الزنقة (الـ network).

نفس المهنة (الطبخ = JavaScript). البلاصة هي اللي كتبدّل الـ APIs.

6

🔍 الخطوات فدماغك

  1. كتبي file .ts أو .js.
  2. ما كتحطّيهش فـ page. كتشغّليه بـ node fichier.js.
  3. V8 كيقرا الـ code.
  4. إلا لقيتي document → غادي يطيح. ما كاينش.
  5. إلا لقيتي قراءة file أو HTTP server → هادشي مسموح هنا.

7

💻 code صغير

الـ block الأولى: اللي كتعرفيه فالـ UI. الثانية: نفس الفكرة فـ Node. ما تشغّلي والو دابا إلا ما بغيتيش.

// Browser — كتعرفيه
const el = document.querySelector("#app");
el.textContent = "سلام";
// Node — ما كاينش document
const name = process.env.APP_NAME ?? "agent";
console.log("سلام من server:", name);

// من بعد نقدروا نفتحو server، نقراو file، ونعيطو لـ LLM

console.log كاين فالجوج. document غير فـ browser. process.env غير فـ Node (أو server).

8

⚛️ مقارنة مع Next.js

اللي كتعرفيه شنو هو أصلاً
component فـ React كيتحسب غالباً فـ browser (أو SSR)، كيلمس UI
API route / server action server code. قريب من Node، داخل framework ديال Next
file Node وحدو نفس فكرة الـ route، بلا framework. نتي المسؤولة على الـ server

ملي كتبتي app/api/... فـ Next، راك أصلاً لمستي عالم Node. هاد الـ lesson غير كيسمّي البلاصة: هاد الـ code ماشي ديال الـ page.

9

🌍 example واقعي

فـ course ديالنا: الـ user كتكب فـ React. الـ message ما خصّهاش تبقى غير فـ browser. خصها تمشي لـ server ديال Node (أو Worker من بعد)، هو اللي ينادي الـ model، يشغّل tools، ويكتب نتيجة الـ eval فـ file أو database.

10

🧪 تمرين

🟢 ساهل

كتبي sentence واحدة: واش هاد الـ line يخدم فـ browser، فـ Node، ولا فالجوج؟ علاش؟

بعد ما تجاوبي، فتحي

غير فـ browser. document هو الـ page. Node ما عندوش page.

13

⚠️ أغلاط شائعة

  • «خصني نبدل الـ language لـ Python باش نولي AI.» — لا. فهاد الـ course Node كافي.
  • «Node = npm برك.» — npm هو tool. Node هو اللي كيجري الـ code.
  • «نقدر نستعمل document فـ Node.» — لا.
  • «Cloudflare و Node نفس الشيء.» — لا. غادي نفصلوهم من بعد.
