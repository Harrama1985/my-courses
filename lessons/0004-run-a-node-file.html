الدرس 3 · Node.js · مفهوم واحد · English بشوية

node كيدير run لـ file

فالدرس اللي قبل، شفنا بلي Node هو runtime. اليوم غير خطوة وحدة: عندك file ديال JavaScript، كتكتبي command فـ terminal، وهو كيدير run.

Browser / page Terminal / Node File Error
هاد الدرس فيه كلمات English جديدة، قلال. الجملة تبقى دارجة. الكلمة الجديدة داخل صندوق، بحال run. اللائحة كاملة فـ ENGLISH.md باش ترجعي ليها.

1

🎯 شنو كنتعلمو؟

باش تشغّلي file، كتكتبي: 

$ node hello.js

node هي الـ command. hello.js هو اسم الـ file. من بعد هاد السطر، Node كيدير start من الـ top ديال الـ file، سطر بسطر، then كيدير stop ملي يسالي.

المصدر: الطريقة العادية هي node مع اسم الـ file، وخاصك تكوني فـ same folder. Run Node.js scripts from the command line

2

🤔 علاش فهاد الـ course؟

من بعد، ملي نقيسو الـ agent، القياس ما غاديش يكون button فـ page. غادي يكون file كتكتبي ليه node score.js. هو كيسول، كيحسب، وكيدير print للـ score فـ terminal.

إلا ما عرفتيش هاد الـ command، كلشي اللي من بعد (الـ npm، الـ server، الـ env) غادي يبقى معلق. اليوم غير هاد الباب.

3

🧠 شرح دارجة، ببطء

الـ terminal هي نافذة كتكتبي فيها أمر، وما كتشوفيش فيها page. ما كاينش button، ما كاينش canvas. كاينة غير الكتابة، والسطر اللي كيرجع.

الـ command ديال اليوم فيها جوج حوايج، بهاد الترتيب: first الكلمة node، then اسم الـ file. بلا اسم الـ file، Node ما عندو والو يشغّل.

الـ folder هي البلاصة اللي فيها الـ files. الـ terminal كيكون واقف فـ folder وحدة. خاص هاديك تكون same folder اللي فيها hello.js. because Node كيقلّب على الـ file فين واقف، ما كيقلّبش فالدار كاملة.

console.log كيدير print: كيخرج نص. فالـ browser كتشوفيه فـ DevTools. هنا كتشوفيه فـ terminal. نفس الـ function، بلاصة أخرى.

ملي آخر سطر يسالي، والـ code ما بقاش كيتسنّى network ولا server، البرنامج كيدير stop بوحدو. كترجعي للـ terminal وتقدري تكتبي command جديدة. هادشي same الفكرة ديال script قصير، ماشي app باقية محلولة.

4

🌍 تشبيه

page فـ browser

بحال لوحة فالقاعة. الناس كيشوفوها. كتضغطي على button واللوحة كتبدّل.

file فـ terminal

بحال ورقة وصفة فالمطبخ. كتقرايها من الـ top. first السطر اللول، then اللي من بعدو. النتيجة كتخرج على الورق، ماشي على اللوحة ديال القاعة.

إلا الورقة ماشي فـ same folder (نفس الدرج)، كتجي error: ما لقيتيهاش.

الرسم 5 — same folder، ولا error

هادي خدامة

$ cd course
$ node hello.js
سلام

cd كدخّلك لـ folder. من بعد، same folder فيها hello.js.

هادي error

$ node hello.js
Error: Cannot find module
'/Users/you/hello.js'

الـ terminal واقف فـ folder أخرى. because الـ file ما كاينش قدامو. الرسالة الحقيقية فيها سطور كتر. السطر المهم: Cannot find module.

6

🔍 الخطوات فدماغك

  1. كتكتبي الـ code فـ file سميتو hello.js.
  2. كتحلّي terminal.
  3. كتدخلي لـ folder بالـ cd، باش تكوني فـ same بلاصة مع الـ file.
  4. كتكتبي node hello.js وكتضغطي Enter.
  5. Node كيدير start من الـ top.
  6. كل console.log كيدير print فـ terminal.
  7. آخر سطر يسالي، then كيدير stop.
