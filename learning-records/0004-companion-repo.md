# الخريطة ولات ريبو Hendrixer

المتعلمة طلبات ناخدو الكورس من [Hendrixer/ai-engineering-fundamentals](https://github.com/Hendrixer/ai-engineering-fundamentals) ونعاودوه بالدارجة، بأمثلة ورسوم، لواحد يالله بادي. المنتج ديال الريبو: لوحة Excalidraw + شات كيولي agent كيرسم بعناصر، ماشي صورة. القياس بالـ evals. Node.js باقي السيرفر ديالها؛ Python باقي خارج.

**Implications**: الدرس الجاي يبقا فـ Node (الدرس 2 ديجا كاين) قبل ما ندخلو لتفاصيل Cloudflare Agent. ما نعاودوش «شنو هو AI Engineer» إلا بان سوء فهم. المصطلح التقني يبقى إنجليزي للحد الأقصى: function، browser، canvas، tool، element، text، image، course، message، request، response، user، data. الدارجة للجملة فقط.
