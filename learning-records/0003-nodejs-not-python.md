# السيرفر هو Node.js، ماشي Python

المتعلمة عندها خلفية جزئية على Node.js وبغات تتعلّمو داخل هاد الكورس. Python خرج من الأساس. الكود ديال الـ agent والـ evals والـ backend غادي يكون Node + TypeScript. Cloudflare باقي فالخريطة كـ deploy/runtime، مع توضيح أنه ماشي نفس Node.

**Implications**: تزاد فصل Node.js للفرونت قبل Cloudflare. الدروس ما تعاودش JS. تقارن مع browser و Next.js route handlers.
