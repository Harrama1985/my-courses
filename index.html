12 lessons من الـ repo + Node

الترتيب من Hendrixer/ai-engineering-fundamentals. فصل Node.js زاديناه ليك نتي، قبل ما ندخلو لـ Cloudflare.

النهار 1 — تبني وتقيسي

1. شنو هو AI Engineer

lesson جاهز

الـ model محرّك جاهز. نتي كتركّبي حولو canvas و chat، وتقيسي قبل ما تبدّلي.

Node.js للفرونت

lesson جاهز

نفس JavaScript، برا الـ browser. هاد الفصل زيدناه حنا، ماشي فترتيب الـ repo، حيت الـ server ديالك Node.

2. أول Cloudflare Agent

من بعد

الـ agent كيستقبل الـ message، كيختار tool، وكيرجّع elements. أول rectangle كيظهر على الـ canvas.

3. تجربة الـ chat

React

الـ response كيوصل chunk بـ chunk، وكتشوفي «كيرسم…» ملي الـ tool خدامة.

4. انضباط الـ eval

الـ score

list ديال examples ثابتة. كتشغّليهم باليد اللولة، وكتسجّلي baseline score.

5. مصحّحون أوتوماتيك

الرقم

code كيشوف واش الـ schema صحيح، و model كيحكم على جودة الـ diagram. نفس الـ list، كل مرة.

النهار 2 — تحسّني حاجة وحدة وتعاودي تقيسي

6. Context engineering

شنو تعطي للـ model

الـ instructions، حالة الـ canvas، و history ديال الـ chat. بزاف ديال الـ text كيضيّع الـ model.

7. tools أحسن

الـ model كيدير

بدّل element، قرا الـ canvas، ورّي للـ model example كيفاش ينادي الـ tool.

8. RAG

داتا خاصة

الـ model ما حافظش أنماط الـ diagrams ديالك. كتجيب الـ chunk القريب وتعطيه ليه.

9. Gen UI

ماشي text برك

نتيجة الـ tool كتولي component ديال React: معاينة، ولا كروت تختار منهم.

10. إنسان فالحلقة

الثقة

قبل الـ delete أو الـ change الكبير، الـ chat كيسول: وافقي ولا لا.

11. معمارية الـ agent

ماشي حلقة وحدة

يشوف، يخطّط، من بعد يرسم. agent صغير ومركّز، ماشي agent كيدير كلشي.

12. Data flywheel

الاستعمال كيولي test

كل Undo هو signal. الـ correction ديال الـ user كيولي example جديد فـ eval.

شنو غادي يكون عندك فالأخر

  • app فيه chat و agent، ماشي demo كيتكسّر.
  • طريقة تقيسي بيها: قبل ما تبدّلي، وبعد ما تبدّلي.
  • agent كيستعمل tools وكيقدر يقرا داتا خاصة.
  • كل هادشي بـ Node.js + TypeScript + React. ماشي Python.
